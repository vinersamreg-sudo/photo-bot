# Будущее развитие сайта

1. Заменить CTA на подтверждённый MAX deep link и добавить campaign parameters, которые бот сохраняет без персональных данных.
2. Создать индексируемые страницы сценариев: деловой портрет, замена фона, восстановление, фото на памятник. Не генерировать пустые SEO-страницы.
3. После согласий добавить реальные кейсы с описанием задачи и числа исправлений.
4. Подключить privacy-friendly funnel: landing CTA → start bot → source uploaded → preview delivered → unlock. Не отправлять фото или prompt в аналитику.
5. Добавить страницу статуса и канал поддержки перед оплатой.
6. После появления утверждённой цены показать её рядом с CTA без скрытых условий.
7. Зарегистрировать сайт в Яндекс Вебмастере, добавить IndexNow и отслеживать запросы без накрутки ключевых слов.
8. Рассматривать CMS только когда контент перестанет удобно обновляться pull request-ами; до этого статический сайт быстрее и безопаснее.
