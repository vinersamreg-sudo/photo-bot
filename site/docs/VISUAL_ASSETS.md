# Visual assets provenance

Все четыре исходных изображения созданы встроенным image generation tool специально для продукта, который сейчас называется Ravuna, 15.07.2026. Люди вымышлены; чужие или пользовательские фотографии не использованы. В репозитории хранятся только оптимизированные WebP-варианты.

## Prompt summaries

- `hero-*`: естественный editorial portrait вымышленной взрослой женщины, ivory/lavender studio, negative space, без текста и чрезмерной ретуши;
- `business-*`: горизонтальная пара одного вымышленного мужчины; обычный снимок → деловой портрет, идентичность и ракурс сохранены;
- `restore-*`: синтетический портрет 1950-х; умеренно повреждённая бумажная фотография → бережно восстановленная чёрно-белая версия;
- `background-*`: горизонтальная пара одной вымышленной женщины; изменён только фон, лицо, одежда и поза сохранены.

Use case: `ads-marketing`. Ограничения: no text, logo, watermark, UI, competitor style, neon effects or real-person likeness request.

Перед заменой материалов реальными кейсами требуется документированное согласие владельца фотографии и запрет на публикацию original без такого согласия.
