# Roadmap

## Этап 0 — production-фундамент

Hetzner, SSH hardening, UFW/fail2ban, отдельный deploy user, Python 3.12, CI/CD, healthcheck, secret scan и документация выполнены. Новый production OpenAI-ключ настроен; встроенный `openai-check` получил HTTP 200 и подтвердил доступность `gpt-image-2`.

## Этап 1 — технический image vertical slice

Реализовать image service с fake и OpenAI gateway, валидацию входного изображения/инструкции, контролируемые temp-файлы, timeout/retry и интеграционные тесты без мессенджера. Первый vertical slice — изменение исходного фото по одной инструкции с сохранением узнаваемости; затем фон/портрет и восстановление.

## Этап 2 — пользовательский канал

MAX выбран первым исследуемым каналом, но transport-интеграция требует отдельного технического подтверждения. Реализовать состояния диалога, сценарное минимальное меню, загрузку фото, один уточняющий вопрос при неоднозначности, итоговое ТЗ, предварительное отображение цены/срока/хранения, подтверждение операции, preview + файл результата и понятные ошибки. Состояние фото и prompt не должно теряться при повторном открытии. Добавить systemd, restart policy и operational check реального процесса.

## Этап 3 — операции и монетизация

SQLite для операций и идемпотентности, тарифная модель после измерения all-in себестоимости `gpt-image-2`, платежный провайдер, баланс, автоматический технический возврат, correction-flow и аудит без хранения секретных или лишних персональных данных. Показывать `списано / возвращено / остаток / operation_id`.

## Этап 4 — закрытая beta

Лимиты, кнопка и команда удаления, политика хранения/удаления, поддержка, метрики качества/стоимости/median/p95 времени, correction/refund rate, алерты и backup базы. Утвердить публичный бренд и юридические тексты до внешнего запуска. Бесплатная beta-операция допускается только при abuse-control и полном покрытии ключевого edit.

## Этап 5 — масштабирование по данным

Оптимизировать конкурентность и ресурсы. Очередь, Redis, worker-процессы, объектное хранилище или новый сервер рассматриваются только после подтверждения bottleneck метриками.
