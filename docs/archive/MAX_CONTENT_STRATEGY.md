# Official MAX channel content strategy

## Promise

Show what Ravuna can do with honest before/after demonstrations. Sell the visible
result, not a model name. Never imply a demonstration is a customer order.

Every post ends with:

> 🎁 Получите 2 бесплатные обработки<br>
> 👇 Попробовать Ravuna

The link always contains `utm_source=max`, `utm_medium=channel`,
`utm_campaign=demo_posts` and a post-specific `utm_content`.

## Weekly rhythm

| Day | Format |
|---|---|
| Monday | Before/after |
| Tuesday | Photo tip |
| Wednesday | Remove objects/person |
| Thursday | Replace clothes |
| Friday | Replace background |
| Saturday | Restoration |
| Sunday | Best approved case of the week |

The plan is a rotation, not a reason to publish weak work. Empty or failed quality
slots remain unpublished.

## Copy style

- task → factual result → demo disclosure → CTA;
- short sentences and observable claims;
- no “к нам обратилась…”, testimonials, invented orders or emotional biography;
- no unverified promise that faces/details were preserved;
- no technical provider/model vocabulary in user copy;
- Russian copy comes only from versioned deterministic templates.

## Mandatory disclosure

Every body contains, without exception:

> Демонстрационный пример Ravuna.<br>
> Изображения созданы специально для демонстрации возможностей сервиса.

## Metrics

Track views, clicks, reactions, comments, CTR and conversion to the bot. Compare
categories and formats only after sufficient published samples. Do not optimize
for views by weakening disclosure or inventing social proof.
